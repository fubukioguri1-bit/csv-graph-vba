# 5.2.1 Unit Tests – ModCSV

## テスト目的
`LoadAndAggregate` が **ニックネーム別に正しい件数** を集計し、`Summary` シートに正しく書き込むことを検証する。

## 前提条件
- テスト実行時に `sample/nickname_list.csv` が存在すること。  

## テストコード（Rubberduck）

```vba
Option Explicit

Public Sub Test_LoadAndAggregate_CountsCorrectly()
    Dim testCsv As String
    testCsv = ThisWorkbook.Path & "\sample\nickname_list.csv"
    
    ' 実装関数呼び出し
    Call LoadAndAggregate(testCsv)
    
    Dim ws As Worksheet: Set ws = ThisWorkbook.Sheets("Summary")
    
    ' 期待結果をハッシュで保持
    Dim expect As Object
    Set expect = CreateObject("Scripting.Dictionary")
    expect.Add "taro", 1
    expect.Add "hana", 2
    expect.Add "jiro", 1
    expect.Add "shiro", 1
    expect.Add "go", 1
    
    Dim i As Long, lastRow As Long
    lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row
    
    For i = 2 To lastRow
        Dim nick As String, cnt As Long
        nick = ws.Cells(i, 1).Value
        cnt = ws.Cells(i, 2).Value
        Assert.AreEqual expect(nick), cnt, "ニックネーム '" & nick & "' の集計が期待と違います"
    Next i
End Sub
