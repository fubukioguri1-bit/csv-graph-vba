# 6.1 Risk Register
| ID | リスク | 発生確率 | 影響度 | 緩和策 |
|----|--------|----------|--------|--------|
| R‑001 | CSV の列名が「ニックネーム」以外（例: `NickName`, `名前`） | 中 | 高 | 正規表現で `*name*` 系列を検索し、見つからなければエラーで停止し、ログに詳細を書き込む。 |
| R‑002 | 大容量 CSV（数千行）で処理が遅延 | 低 | 中 | `Application.ScreenUpdating = False`、`Application.Calculation = xlCalculationManual` を一時的に無効化し、処理後に元に戻す。 |
| R‑003 | ユーザーがマクロ実行をブロック（セキュリティ設定） | 中 | 高 | 起動時に `Application.AutomationSecurity` をチェックし、ブロックされている場合は警告ダイアログで有効化を促す。 |
| R‑004 | `graph.png` の保存先フォルダに書き込み権限が無い | 低 | 中 | エラーハンドリングで `LogError` に記録し、ユーザーに「保存先の権限を確認してください」旨のメッセージを表示。 |
| R‑005 | GitHub Actions の Windows ランナーで Rubberduck が動作しない | 低 | 中 | CI ステップで `choco install rubberduck -y` を実行し、失敗した場合は代替 PowerShell スクリプトでテストを実行する fallback を用意。 |
