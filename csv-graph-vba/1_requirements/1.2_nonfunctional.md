# 1.2 Non‑Functional Requirements

| 項目 | 要件 |
|------|------|
| NFR‑001 **可用性** | ローカルで 99.9 % の正常起動率（マクロ実行時にクラッシュしない） |
| NFR‑002 **性能** | 1,000 行程度の CSV を **2 秒以内** に処理完了 |
| NFR‑003 **対応 Excel バージョン** | Excel 2019 以降、または Microsoft 365（64 ビット推奨） |
| NFR‑004 **セキュリティ** | 外部サーバーへの通信は一切行わず、すべてローカルで完結 |
| NFR‑005 **保守性** | VBA は **モジュール単位** に分割し、各モジュールに必ずコメントを付与 |
| NFR‑006 **ロギング** | 失敗時は必ず `error.log` にタイムスタンプ付きで出力 |
