# 4.1 CI/CD (Continuous Integration & Deployment)
## GitHub Actions ワークフロー (`.github/workflows/ci.yml`)
```yaml
name: CI
on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install markdownlint
        run: npm install -g markdownlint-cli
      - name: Lint markdown files
        run: markdownlint "**/*.md"
  mermaid:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install mermaid-cli
        run: npm install -g @mermaid-js/mermaid-cli
      - name: Validate Mermaid diagrams
        run: |
          find . -name "*.md" -exec grep -l "mermaid" {} \; | \
          xargs -n1 mmdc -i {} -o /dev/null
  vba-test:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      # インストール例（Chocolatey）※イメージに含まれていない場合はここでインストール
      - name: Install Rubberduck CLI
        run: choco install rubberduck -y
      - name: Run VBA unit tests (Rubberduck)
        run: |
          rubberduck run-tests -ProjectPath src/modules
