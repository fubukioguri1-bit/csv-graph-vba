# 0.1 背景

社内の研修・勉強会では、**実施日・場所・参加者氏名・ニックネーム** の 4 列からなる CSV が出席者リストとして配布されています。  

現在の業務フロー  
1. CSV を手作業で開く  
2. ニックネーム列だけを抽出し、手動でピボットテーブルやグラフを作成  
3. 集計結果をレポートに貼り付け  

この手順は **時間がかかる** うえ、**ヒューマンエラー** が起きやすく、個人情報保護（氏名の非表示）という要件にも合致していません。  

本ツールは、上記作業を **VBA だけで自動化** し、  
- ニックネーム別参加者数の即時集計  
- 棒グラフの自動生成 & PNG 出力  
- 同シートへの貼り付け  

を実現します。
