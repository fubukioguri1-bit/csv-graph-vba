# 4.1 CI/CD
## ワークフロー（.github/workflows/ci.yml）
```yaml
name: CI
on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install markdownlint
        run: npm install -g markdownlint-cli
      - name: Lint markdown
        run: markdownlint "**/*.md"
  mermaid:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Install mermaid-cli
        run: npm install -g @mermaid-js/mermaid-cli
      - name: Validate mermaid diagrams
        run: |
          find . -name "*.md" -exec grep -l "mermaid" {} \; | \
          xargs -n1 mmdc -i {} -o /dev/null
  vba-test:
    runs-on: windows-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up VBA environment (Office 365)
        # ここでは、Rubberduck のテストランナーをインストール・実行
      - name: Run VBA unit tests
        run: |
          # 例: PowerShell で Rubberduck CLI を呼び出す
          rubby duck run-tests -ProjectPath src/modules
